## ⚙️ راهنمای نصب | Installation Guide

### فارسی
1. فایل APK مناسب گوشی خود را از لیست بالا دانلود کنید.  
2. وارد **تنظیمات گوشی** شوید و گزینه‌ی **اجازه نصب از منابع ناشناس (Install from unknown sources)** را فعال کنید.  
3. فایل دانلودشده را باز کرده و روی **Install** بزنید.  
4. پس از نصب، آیکون برنامه در لیست اپلیکیشن‌ها ظاهر می‌شود.  

### English
1. Download the appropriate APK file from the list above.  
2. Go to your phone’s **Settings** and enable **Install from unknown sources**.  
3. Open the downloaded file and tap **Install**.  
4. Once installed, the app icon will appear in your app drawer.

## 🔍 انتخاب نسخه مناسب (معماری CPU) | Choosing the Right Version (CPU Architecture)

### فارسی
برای اجرای صحیح برنامه باید نسخه‌ی مناسب معماری CPU گوشی خود را انتخاب کنید:  
- **arm64-v8a** → بیشتر گوشی‌های جدید (۶۴ بیتی)  
- **armeabi-v7a** → گوشی‌های قدیمی‌تر (۳۲ بیتی)  
- **x86_64** → برخی تبلت‌ها یا شبیه‌سازها  

**چطور بفهمیم؟**  
- ساده‌ترین راه نصب اپلیکیشن‌هایی مثل [CPU-Z](https://play.google.com/store/apps/details?id=com.cpuid.cpu_z) یا [AIDA64](https://play.google.com/store/apps/details?id=com.finalwire.aida64) است.  
- در بخش **CPU / ABI** معماری دقیق نوشته می‌شود (مثلاً `arm64-v8a`).  
- اگر مطمئن نیستید، نسخه‌ی **all-abi** را نصب کنید.  

### English
To run the app correctly, you need to choose the APK that matches your phone’s CPU architecture:  
- **arm64-v8a** → Most modern devices (64-bit)  
- **armeabi-v7a** → Older devices (32-bit)  
- **x86_64** → Some tablets or emulators  

**How to check?**  
- Install apps like [CPU-Z](https://play.google.com/store/apps/details?id=com.cpuid.cpu_z) or [AIDA64](https://play.google.com/store/apps/details?id=com.finalwire.aida64).  
- Look under **CPU / ABI** to see your device’s architecture (e.g., `arm64-v8a`).  
- If unsure, download the **all-abi** version which works on most devices.
